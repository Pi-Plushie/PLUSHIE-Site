# PLUSHIE

&#x09;	⊚\_⊚ 

Programming Language Universal \& Sequential for Heuristic Intelligent Evolution

(Programmation en Langage Universel Séquentiel et Heuristique pour une Intelligence Évolutive)



PLUSHIE is an experimental minimal computational system exploring:



\- structural homogeneity

\- recursive memory structures

\- emergence

\- self-transformation

\- minimal instruction sets



PLUSHIE is not designed as a production language.



It is an exploration space.
