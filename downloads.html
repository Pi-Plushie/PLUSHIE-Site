🧪 Interface de test PLUSHIE

L’interface publique permet :

  • d’exécuter des fichiers textes en PLUSHIE ;
  • d’observer la mémoire interne ;
  • d'écrire son propre code PLUSHIE et le tester ;
  • d’expérimenter localement.

Plateforme actuellement supportée : Windows

🚀 Démarrage rapide

  1. Téléchargez plushie-public.exe.
  2. Téléchargez plusbase.mem.
  3. Placez les fichiers .txt dans le même dossier.
  4. Lancez l’interface.
  5. Appuyez sur le bouton réinitialiser pour charger ini.txt
  6. Chargez les fichiers de code et observez, en suivant le tutorial.

⚠ Nature expérimentale

PLUSHIE est actuellement un projet expérimental.

Certains comportements peuvent être surprenants, instables ou volontairement non conventionnels.

Les exemples fournis ont pour objectif d’explorer des comportements émergents et des modèles inhabituels de programmation.

Restez prudents dans vos téléchargments et vérifiez l'absence de virus des fichiers que vous téléchargez
